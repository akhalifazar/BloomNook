# BloomNook

Syncs online banking account data from various institutions into a single, unified dashboard view.

With BloomNook, you get a lightweight tool that stays out of your way.

**What you get**

- Syncs online banking account data
- from various institutions into a
- single, unified dashboard view

## Key Features

- Syncs online banking account data
- from various institutions into a
- single, unified dashboard view

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/BloomNook.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
